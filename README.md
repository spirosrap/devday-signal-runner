# Signal Runner

A small static browser game built for an OpenAI DevDay 2026 submission idea.

- GPT-5.5 generated the game copy, palette, and asset prompts.
- Image Gen (`gpt-image-1`) generated the playable background and sprite atlas.
- The runtime is plain HTML/CSS/JS and is safe for GitHub Pages because it contains no API key.

Open `index.html` in a browser or serve this folder locally.
